حریم خصوصی

خب، بریم سراغ یکی از اون چیزایی که شاید خیلی‌ها حوصله خوندنش رو نداشته باشن، ولی به نظرم بهتره واضح و ساده درباره‌ش حرف بزنیم. :)

حریم خصوصی توی مابورای برامون مهمه. از اول هم قرار نبوده برای استفاده از یه جای ساده برای نوشتن، کلی اطلاعات شخصی ازت بخوایم. به همین خاطر مابورای برای استفاده معمول به ایمیل، شماره تلفن یا رمز عبور نیاز نداره.

وقتی می‌خوای یه پست منتشر کنی، ممکنه یه اسم برای نمایش انتخاب کنی و اگر دوست داشتی یه عکس هم برای خودت قرار بدی. همین. قرار نیست برای نوشتن یه متن، یه پرونده کامل از اطلاعات شخصی‌ات ساخته بشه.

البته مثل هر سرویس اینترنتی دیگه‌ای، ممکنه بعضی اطلاعات فنی برای اینکه سایت درست و امن کار کنه پردازش بشن. مثلاً اطلاعاتی مثل IP یا بعضی داده‌های فنی مربوط به درخواست‌ها ممکنه برای امنیت، جلوگیری از اسپم و سوءاستفاده یا بررسی مشکلات سرویس مورد استفاده قرار بگیرن.

اگر لازم باشه چنین اطلاعاتی برای مدت مشخصی نگهداری بشن، تلاش می‌کنیم تا جای ممکن به شکل محافظت‌شده یا مشتق‌شده نگهداری بشن و از اون‌ها برای شناسایی عمومی کاربران استفاده نشه. هدف از این اطلاعات، بیشتر حفظ امنیت و سالم نگه داشتن سرویسه، نه اینکه بدونیم پشت هر نوشته دقیقاً چه کسی نشسته.

یه نکته مهم درباره پست‌ها هم وجود داره: چیزی که منتشر می‌کنی، عمومی محسوب می‌شه. بنابراین بهتره اطلاعات خصوصی، محرمانه، رمز عبور، کلید دسترسی، اطلاعات حساب یا هر چیزی که قرار نیست بقیه ببینن رو داخل پست قرار ندی. اینترنت کلاً جای خوبی برای گذاشتن اطلاعات محرمانه نیست. :))

ممکنه مابورای برای بعضی قابلیت‌های ضروری از Cookie یا فناوری‌های مشابه استفاده کنه؛ مثلاً برای نگه داشتن بعضی تنظیمات یا درست کار کردن بخش‌هایی از سایت. این موارد برای تبلیغات شخصی‌سازی‌شده یا فروش اطلاعات شخصی استفاده نمی‌شن.

مابورای از GitHub برای نگهداری و انتشار بخش‌هایی از پروژه استفاده می‌کنه. چون پروژه متن‌بازه، بخش‌هایی از کد و ساختار پروژه عمومی هستن. با این حال، اطلاعات محرمانه یا کلیدهای دسترسی نباید هیچ‌وقت داخل کد عمومی یا محتوای عمومی پروژه قرار بگیرن.

در کل، سعی ما اینه که تا جای ممکن اطلاعات کمتری ازت بخوایم و فقط چیزهایی رو پردازش کنیم که برای کارکرد، امنیت و نگهداری سرویس لازم باشن. اینجا قرار نیست برای نوشتن یه پست، مجبور باشی هویت واقعی یا اطلاعات شخصی زیادی در اختیارمون بذاری.

اگر هم روزی تغییری در نحوه استفاده از اطلاعات یا این سیاست ایجاد بشه، نسخه جدید همین صفحه منتشر می‌شه تا همیشه بتونی ببینی چه چیزهایی تغییر کرده.

خلاصه اینکه: تا جای ممکن، کمتر بدونیم.
مابورای قراره جای ساده‌ای برای نوشتن باشه، نه جایی برای جمع کردن اطلاعات آدم‌ها.
